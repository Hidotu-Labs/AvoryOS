# Firmware images copied from linux-firmware into the AvoryOS disk image.
#
# One path or glob per line, relative to the linux-firmware tree root.
# scripts/linux-firmware-install.sh copies every match into
# build/firmware/lib/firmware/, which the top-level GNUmakefile installs at
# /lib/firmware in the disk image (Phase 6 C4).
#
# Pinned ref: linux-firmware 20260910 (LINUX_FIRMWARE_REF in the install
# script).  Keep this list exact: shipping the whole linux-firmware tree is
# hundreds of megabytes, and amdgpu only needs its own blobs.  Add names in
# the same change as the boot that requests them; the Phase 5 firmware
# self-test CRC-checks every staged file against the staging host.
#
# Raphael (RDNA2 iGPU): GC 10.3.6 / MP0-MP1-MP2 13.0.5 / DCN 3.1.5 /
# SDMA 5.2.6 / VCN 3.1.2, pinned by the Phase 6 C3 IP dump.
#
# Notes for this ASIC:
#   - no smu_13_0_5.bin: smu_v13_0_5's pptable_funcs omit .init_microcode,
#     so smu_init_microcode() is a no-op and no SMU file is requested (the
#     name does not exist in linux-firmware);
#   - no psp_13_0_5_sos.bin: 13.0.5 is TOC-based (psp_13_0_5_toc.bin +
#     psp_13_0_5_ta.bin) and psp_v13_0_init_microcode() never asks for SOS;
#   - no jpeg blob: jpeg_v3_0's sw_init loads no firmware (JPEG shares the
#     VCN image).
