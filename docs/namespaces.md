# Browser sandbox namespaces

The original Epiphany failure was bubblewrap's rejected `clone(0x2c020011)`:
private mount, UTS, IPC and PID namespaces. The kernel now implements these
contexts, capability drops, no-new-privileges and classic-BPF seccomp filters.
WebKit's private network request is also supported as an isolated, disconnected
network context. The browser sandbox remains enabled.

## Ownership and confinement

UTS contexts have independently locked hostname/domain values. IPC contexts
partition System V shared-memory and semaphore keys and IDs. Existing attached
shared-memory mappings survive a namespace change; destroying the last task
reference removes the namespace's objects and their ownership references.
Ordinary fork/clone/vfork inherit namespace references; exec retains membership.
Namespace IDs are not recycled. Combined clone/unshare prepares new contexts
before committing them, so an allocation failure cannot partially change the
parent's membership.

Mount contexts own private mount tables. View vnodes preserve the backing inode,
mount identity and path ancestry separately. Bind and recursive bind mounts,
read-only remount, move, detach, private tmpfs/proc/devpts, chroot and both
bubblewrap pivot_root sequences operate on the calling task's view. Absolute
paths, symlink targets and `..` honor the filesystem root. Descriptor magic links
retain the actual node, including across pivots. The global `/dev` shortcut is
not used inside a confined view. Read-only mounts reject mutations and shared
writable mappings, including later mprotect upgrades; private copy-on-write
mappings remain writable. NOSUID, NODEV and NOEXEC restrictions are enforced.

`openat2` implements rooted/beneath resolution and no-symlink, no-magic-link and
no-cross-mount policies. `mount_setattr` applies supported attributes to one
mount or recursively. Unknown attributes, mount APIs, propagation modes and
namespace types return errors instead of silently advertising protection.

[PID namespaces](pid-namespaces.md) preserve global kernel IDs while translating
public IDs, waits, signals, process groups and proc views. Namespace init is
PID 1; its death kills the namespace's remaining tasks and prevents new children.
[Capabilities and private networking](capabilities.md) describes irreversible
privilege drops and the deliberately disconnected private IP transport. User,
cgroup and time namespaces, setns, and Linux nsfs namespace handles remain
unsupported. Namespace identity files are not usable setns descriptors.

## Seccomp

Filters are verified classic BPF with forward control flow, bounded loads and
scratch-memory initialization checks. Immutable reference-counted chains survive
fork and exec; stacking cannot relax an existing filter. TSYNC publishes a chain
to compatible threads or returns the offending namespace-visible TID. ALLOW,
ERRNO, TRAP, KILL_THREAD and KILL_PROCESS are enforced. Unsupported actions kill
conservatively and feature discovery does not advertise them. Native and i386
entry paths both apply the filter with the original architecture and arguments.
SIGSYS TRAP supplies the syscall, architecture, instruction address and filter
data to the signal handler. Strict mode, notification and ptrace trace actions
are not implemented.

PR_SET_NO_NEW_PRIVS is irreversible and inherited. It suppresses set-ID exec
transitions and capability gains. PR_GET_SECCOMP and proc status report actual
filter state. A null filter pointer returning EFAULT is an expected libseccomp
probe; it is not itself a launch failure.

## Regression tests

Run `make test-sandbox` after the normal toolchain/ISO setup. Host sanitizer tests
exercise the actual UTS/PID implementations and BPF verifier/interpreter, including
filters generated by the host libseccomp library. Private four-CPU guests test
namespace inheritance, isolation, teardown, failed operations, PID 1 behavior,
capability drops, seccomp signals/TSYNC, mount escapes and the packaged bubblewrap
binary with sparse-root, `--dev`, `--proc`, read-only binds and WebKit's namespace
options. Every regression uses a separate image and ISO. `AVORY_TEST_KERNEL`
selects an immutable kernel snapshot for the shared guest runner.

The full Epiphany launch probe uses an independent copy of the OS disk, virtual
Xorg and a session D-Bus. Its files and logs live under `build/epiphany-full-boot`;
it never writes the original disk or disables the sandbox. Successful syscall
unit tests alone do not establish that the browser displays a page.

The utilization-clamp sched_setattr EOPNOTSUPP in the supplied log is a separate,
nonfatal WebKit feature probe. WebKit retries with RESET_ON_FORK and disables
further utilization-clamp probes when unsupported; see [scheduler attributes](sched-attr.md).

The later Epiphany abort with a runtime directory under `/tmp` is covered by
[the pivot-root and descriptor-lifetime fixes](epiphany-dbus-runtime-pivot.md),
including the remaining limits of full browser verification.
